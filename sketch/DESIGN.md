## Malibu Scale Color Mapping

- **Canvas / Paper (`#F2F8FC` - Malibu 50):** Soft tinted background canvas.
- **Card Muted / Secondary (`#E2EEF7` - Malibu 100):** Card backgrounds, subtle pills, table headers.
- **Badge Fill / Tint (`#CBE2F2` - Malibu 200):** Selected chips, hover states, sub-borders.
- **Brand Primary (`#4B82C5` - Malibu 600):** Primary CTA buttons, active state indicators, trophy highlights.
- **Brand Primary Hover (`#416FB4` - Malibu 700):** Hover and active states for primary actions.
- **Deep Accent Text (`#3A5B93` - Malibu 800):** High-contrast text on light blue badge backgrounds.
- **Ink Charcoal (`#233148` - Malibu 950):** 2px/3px ink outlines, drop shadows (`shadow-[3px_3px_0px_#233148]`), headings, body text.
